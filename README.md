# qa-login-testing
QA project for testing login functionality using Selenium and manual test cases.

  QA Login Testing Project

📌 Description
This project demonstrates manual and automated testing of a login page using Selenium.
 🛠 Tools Used
- Python
- Selenium WebDriver

✅ Test Scenarios Covered
- Valid login
- Invalid password
- Empty fields
🤖 Automation
A basic Selenium script is used to automate login functionality.
🌐 Demo Website
https://example.com/login

📂 Files Included
- test_login.py → Selenium automation script
- test_cases.txt → Manual test cases
